# Website brand assets

The transparent Calypso wordmark uses outlined Manrope 700 in white and the CAD boat profile in #E3F941. The favicon and app icons use the same profile on #141414.

UCL SVG derives from the supplied University_College_London_logo.xml. The compound background path is inverted with an even-odd rectangle to recover the letter silhouettes; the original portico paths are preserved. White artwork, transparent background, cropped viewBox.

accent-filter.svg maps orange image accents to #E3F941 in sRGB while preserving neutral shades and alpha. Applied to both images and depth canvases.

The sponsor marks in `sponsors/` come from the [Accu graphic published by the Huddersfield BID](https://huddersfield.org/recommended-businesses/accu/), the [Online Oceans website](https://onlineoceans.com/logo-white.svg) and the [Oshen website](https://www.oshendata.com/oshen-logo-sm.png). The Accu wordmark was isolated from the source graphic on a transparent background.
